# Contribuciones

Pequeña guía para colaborar con el proyecto.

1. Haz un fork y crea una rama descriptiva (`feature/<area>-<breve>`).
2. Levanta el proyecto localmente y ejecuta pruebas.
3. Mantén commits pequeños y con mensajes claros.
4. Abre Pull Request con descripción y pruebas realizadas.

Para más detalles, ver `DOCUMENTATION_CHECKLIST.md`.
